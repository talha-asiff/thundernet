# 💫 Quick Start & Compilation  
Clone or download this repository onto your Windows machine.
open vs code (you'll may need to modify the app.cpp code's system() function where server and client files are being compiled and running.  
start the program from app.cpp  
`` g++ -o app app.cpp``  
``.\app.exe``  
the app file will automatically compile and run main.cpp and client.cpp (if setup correctly)
